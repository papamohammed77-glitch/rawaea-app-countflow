## 1. قرار المنتج الذي تم تثبيته

CountFlow ليست صفحة إدارة بيانات ولا شاشة CRUD. المنصة تتكون من تطبيقات لها حدود مسؤولية واضحة:

| التطبيق / الدور | المسؤولية الأساسية | حدود الصلاحية |
|---|---|---|
| Admin / مالك المنصة حالياً | إدارة ملفات الجهات، عمليات الجرد، الكتالوج، العضويات، دورة الجلسة، التسوية والتصدير والتراخيص | إدارة المنصة؛ لا تُعرض هوية المالك أو أعماله لبقية الأدوار |
| Supervisor | قيادة الفريق، إسناد الأفراد والمواقع، مراقبة التغطية والأجهزة والتنبيهات | إدارة ميدانية داخل مشاريعه التي يحمل فيها عضوية مشرف نشطة |
| Counter | عد الصنف في الموقع المسند، مسح الباركود، الكمية والوحدة والدليل الاختياري، المزامنة والعمل دون اتصال | تسجيل نتائج العد في حدود المهمة؛ لا إدارة مشاريع أو حسابات |
| Control / Auditor | مراقبة العمليات والنتائج والتسوية والفروقات والأدلة والحضور | قراءة فقط؛ لا كتابة عد أو توزيع فريق أو إدارة حسابات |

**المبدأ التشغيلي:** Admin ينشئ العملية ويراقبها، Counter ينفذ العد، Supervisor يحل مشكلات الفريق والتغطية، Control يراجع النتيجة لحظياً، ومخرجات الجميع تعود إلى النظام الأم.

**لم يتم تشغيل Export فعلي أو إنشاء Export Record** على بيانات staging؛ جداول العد والتسوية الحالية فارغة.
