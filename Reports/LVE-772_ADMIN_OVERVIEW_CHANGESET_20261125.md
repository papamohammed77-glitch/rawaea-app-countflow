# LVE-772 — ChangeSet قبل التنفيذ: إعادة تصميم لوحة النظرة العامة في CountFlow Admin

**التاريخ:** 25 نوفمبر 2026 (Africa/Cairo)  
**النطاق:** المرحلة التنفيذية الأولى فقط — `countflow-admin.html` / تبويب النظرة العامة.  
**مرجع التنفيذ:** PR #8، الفرع `work/lve-765-admin-ui-final-mainline`، HEAD قبل التعديل `fac717123b38e3ca5603b7379315c68ad05fb7e2`.  
**حدود النطاق:** لا تعديل على Counter أو Supervisor أو Control أو مشروع RAWAEA ERP المرجعي، ولا تغيير في جداول Supabase أو سياسات RLS أو RPC أو Edge Functions أو البيانات التشغيلية.

## الأدلة التي سبقت التعديل

1. فحص مصدر Admin الحالي كشف تكراراً حرفياً في تعريف `renderGlobalOperations`:
   `function renderGlobalOperations(){ function renderGlobalOperations(){`
   وهذا يسبب `SyntaxError: Unexpected token ')'` عند تحليل سكربت الصفحة.
2. فحص GitHub Actions للـHEAD الحالي أظهر 60 اختباراً ناجحاً و2 فاشلين: خطأ JavaScript أعلاه، واختبار Role Scope يستخدم regex لا يطابق ربط الحدث الصحيح بـOptional Chaining.
3. تبويب النظرة العامة الحالي يعرض أربع بطاقات ومخطط حالات وجدول أداء محدوداً؛ ولا يعرض قراءة إدارية مترابطة لمؤشرات المواقع والإسنادات وآخر نشاط، كما أن معدل التغطية الحالي محسوب بمتوسط غير موزون.
4. العرض `public.count_operation_overview` موجود فعلياً ويقدم حقولاً مجمعة للعملية تشمل المنتجات النشطة والمعدودة، أحداث العد، المواقع، الأعضاء المسندين، الإسنادات النشطة وآخر تسجيل. تم التحقق من أن العرض `security_invoker=true`، لذلك تبقى صفوفه محكومة بصلاحيات وRLS الجداول الأساسية للمستخدم الحالي.
5. جدول `count_entries` موجود في منشور Supabase Realtime، ويحمل `project_id`؛ لذلك يمكن ربط تحديث النظرة العامة بأحداث العد دون إنشاء قناة بيانات جديدة أو إضافة صلاحيات.
6. تحقق صلاحيات أعمدة `count_projects` مباشرة: أعمدة `id, client_id, name, code, status, created_at, updated_at` قابلة للقراءة بواسطة `authenticated`، بينما `created_by` غير قابل للقراءة. استعلام الفرع الحالي لا يطلب `created_by`؛ وسيضاف اختبار انحدار صريح لذلك.
